# Chibi collection print masters

All PNG files are tagged at 300 DPI and preserve the original artwork's aspect
ratio. Transparent apparel, sticker, and mug files use a contour cut around the
existing cream/gold badge edge. Poster files are opaque and include 0.125 inch
of bleed on every side.

## Apparel

- Portrait designs: 4500 x 5400 px, transparent canvas
- Original Group Project: 4500 x 4500 px, transparent canvas
- Washington's Boat Club: 5400 x 3600 px, transparent canvas

Use these files for DTG apparel. Keep the artwork centered inside the product
creator's safe area and inspect every garment color at full zoom.

## Stickers

- 1800 x 1800 px, transparent canvas, supports up to 6 inches at 300 DPI

The visible art is a single connected badge silhouette. A 4-inch size is
recommended for designs with smaller lettering and character details.

## Mug

- Liber-Tea: 3300 x 1275 px, transparent two-sided wrap master

The complete design appears on both viewing faces. Confirm the exact provider
template before publishing and make only a proportional resize if required.

## Posters

- Portraits: 3675 x 5475 px for a 12 x 18 inch trim plus bleed
- Original Group Project: 3675 x 3675 px for a 12 x 12 inch trim plus bleed
- Washington's Boat Club: 5475 x 3675 px for an 18 x 12 inch trim plus bleed

These files contain 0.125 inch (37.5 px at 300 DPI) of bleed on each edge. No
crop marks are embedded in the artwork.

## Production method

The approved raster artwork was contour-extracted and resized with
aspect-ratio-preserving Lanczos resampling followed by restrained output
sharpening. No generative redraw, geometric stretching, or content-aware fill
was applied.
